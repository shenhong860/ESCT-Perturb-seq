# Figures

The manuscript figures are generated by:

- `scripts/make_cns_figures.py` (method overview, performance, observed
  non-additivity)
- `scripts/make_fig2_clean.py` (clean-protocol performance figure)

Outputs are written to `ESCT_FIGURE_DIR` (default `outputs/figures/`).
Published figures for the manuscript are maintained in the manuscript
submission package, not in this repository.

Each script writes the combined figure plus one standalone PDF/PNG per panel:

- `figure2_panel_a_pcc`, `figure2_panel_b_dir`, `figure2_panel_c_l2`,
  `figure2_panel_d_tradeoff` from `make_fig2_clean.py`
- `figure3_panel_a_hist`, `figure3_panel_b_scatter`, `figure3_panel_c_top15`
  from `make_cns_figures.py` (legacy figure 2 panels use the
  `figure2_v2_panel_*` prefix)

The standalone panels share the same style as the combined figures and can be
reassembled in an external layout tool.
