# Data

Download the processed scPerturb datasets from Zenodo DOI 14638780.

Expected inputs:

- Norman: `norman_hvg1000.h5ad` + scGPT gene embeddings
- Replogle_exp6: `Replogle_exp6.h5ad` + scGPT gene embeddings
- Wessels: `Wessels.h5ad` + scGPT gene embeddings
- DEG references: `DEG_hvg5000_*.pkl`

For CAPRA, use the official GenePT embedding table from the CAPRA repository.

Large data files are not stored in this repository.
